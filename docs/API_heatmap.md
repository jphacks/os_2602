# ヒートマップAPI（docs/API.md に追記する分）

地図に見えている範囲の測定記録を、マスごとにまとめて返す。マスの平均dBで色を塗り、代表タグのアイコンを重ねる（企画書）。
中身は `main/api_heatmap.py`、マスの決まりは `main/models.py`（`CELLS_PER_DEG_LAT` / `CELLS_PER_DEG_LNG` / `CELL_LEVELS`）。
描くのは `static/js/map.js`（`HeatLayer`）。

## マス目の決まり

国の標準地域メッシュ（JIS X 0410）に合わせている。保存するのは一番細かい10mのマスの番号（`Measurement.cell_x` / `cell_y`）だけで、ヒートマップのマスは番号を割って作る。

**マスの大きさは、地図の拡大率に関係なくいつでも約50m**（`level` は `50m`）。縮小するほどマスが小さく見えて、全体がなめらかに見える。

| `level` | マスの大きさ | 番号 |
| --- | --- | --- |
| `50m` | 緯度1.5秒 × 経度2.25秒（約46m × 57m）。標準の100mメッシュをちょうど2×2に分けたもの | `cell_x // 5`, `cell_y // 5` |

- 10mのマスの番号：`cell_x = floor(経度 × 8000)`、`cell_y = floor(緯度 × 12000)`
- マスの境界は、標準メッシュの境界とぴったり一致する

## GET /api/heatmap

```text
/api/heatmap?south=34.64&west=135.58&north=34.66&east=135.60&time_band=1
```

| パラメーター | 内容 |
| --- | --- |
| south / west / north / east | 見えている範囲（`map.getBounds()` の南西・北東） |
| time_band | 時間帯の `TimeBand.id`（セレクトボックスの値）。省略すると全部の時間帯 |
| mine | `1` なら自分の測定だけ（ローカルマップ）。省略すると全員分（全国マップ） |
| zoom | 送ってもよいが使わない（以前の段階切り替えの名残り） |

### 返すもの（200）

```json
{
  "level": "50m",
  "cell_deg": { "lat": 0.000416667, "lng": 0.000625 },
  "cells": [
    {
      "x": 216950, "y": 83140,
      "avg_db": 71.4,
      "count": 12,
      "out_db": 68.2,
      "out_count": 9,
      "tag": { "id": 1, "name": "電車", "icon": "🚃" }
    }
  ],
  "truncated": false
}
```

- `x` / `y` は50mのマスの番号。四隅は `西端 = x × cell_deg.lng`、`南端 = y × cell_deg.lat`（東端・北端は +1 したもの）
- `avg_db` はマスの中の全部の測定記録の `avg_db` の平均（企画書の `Avg("avg_db")`）
- `out_db` / `out_count` は屋外の記録（`Measurement.is_indoor = False`）だけの平均と件数。屋外の記録が無いマスは `out_db` が `null`
- `tag` はそのマスで一番多く付けられたタグ（代表タグ）。タグが無ければ `null`
- `truncated` が `true` のときは、マスが多すぎて上限で打ち切った（測定の多いマスから残す。拡大すると全部出る）

### 地図での描き方（`static/js/map.js`）

- 1枚のキャンバス（`google.maps.OverlayView`）にまとめて描く。マスが何千あっても軽い
- 測ったマスは、そのマスの平均の色で塗る（屋外の記録があれば屋外の平均、屋内だけなら全部の平均に斜線）
- 測っていないマスは、近くの**屋外の**マスの値から推定して、うすく塗る（地震の震度分布図と同じ考え方）。広げるのは2マス（約100m）まで。屋内の記録は広げない

### エラー（400）

`{"error": "画面にそのまま出せる文言"}`。範囲・時間帯の値がおかしいとき。

## 調整できる値（`main/api_heatmap.py` の先頭）

- `MAX_CELLS` … 1回に返すマスの上限（8000）
- `CELL_LEVEL` … マスの大きさ（`50m`）
- `MIN_USERS` … マスを出すのに必要な人数（今は 1 = 制限なし）。企画書の「自宅を特定させない」に合わせるなら 2 や 3 にする
